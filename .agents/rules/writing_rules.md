# Master Rules & Prohibitions (กฎเหล็กแม่บทและข้อห้ามเด็ดขาด)

เอกสารนี้รวบรวม **กฎเหล็กแม่บท, ข้อห้ามเด็ดขาด (Strict Prohibitions), และมาตรฐานการเขียน** ทั้งหมดของโครงการนิยาย **10000-BC (พลิกยุคหินด้วยรถพัสดุหมื่นชิ้น)**

---

## 🏛️ หมวดที่ 1: กฎเหล็กแม่บทข้อบังคับสูงสุด (Supreme Inviolable Rules)

1. **กฎการอ่านไฟล์ Markdown (.md) ทั้งหมดก่อนเริ่มงานทุกครั้ง (Mandatory Pre-Reading Rule):**
   - ก่อนเริ่มวางแผน ร่าง หรือเขียนบทนิยายตอนใหม่ทุกครั้ง **ต้องเปิดอ่านไฟล์ Markdown (.md) ทั้งหมดในโครงการก่อนเสมอเป็นกฎเหล็ก**
   - ไฟล์บังคับอ่าน: `chapters_summary.md`, `chapters_outline.md`, `fortress_alpha.md`, `items.md`, `character.md`, `inventory.md`, `outline.md`, `story_outline.md`, `prompt.md` และตอนล่าสุดใน `chapters/`
   - *เป้าหมาย:* ป้องกัน Plot Holes, รักษาความต่อเนื่องของไทม์ไลน์, และควบคุมยอดทรัพยากรคงเหลือ (โดยเฉพาะกระสุน .38 ครบ 43 นัด) 100%

2. **กฎมาตรฐานความยาว 80 – 120 บรรทัดเนื้อหาจริง (The 80–120 Non-Blank Lines Standard):**
   - แต่ละบทต้องมีความยาวเนื้อหาจริง **80 – 120 บรรทัด (ไม่นับบรรทัดว่าง)** เทียบเท่า **2,200 – 3,200 คำ** (~8,500 – 12,000 ตัวอักษร)
   - ห้ามเขียนสั้นกุดห้วน (ตอนไคลแมกซ์สงครามใหญ่ขยายได้ถึง 120 – 150 บรรทัด)

3. **กฎการแยกไฟล์ภาษาไทยและภาษาอังกฤษคู่ขนาน (Mandatory Bilingual Narrative):**
   - ทุกตอนต้องสร้างไฟล์แยก 2 ภาษาในโฟลเดอร์ `chapters/` เสมอ:
     * ภาษาไทย: `chapters/chapter_XXX_th.md`
     * ภาษาอังกฤษ: `chapters/chapter_XXX_en.md`
   - พล็อต เหตุการณ์ รหัสพัสดุ และยอดทรัพยากรตรงกัน 100% ฉบับอังกฤษใช้สำนวน Gritty Survival Thriller

4. **กฎการบันทึกสรุปและตัดยอดทรัพยากรทุกตอน (Mandatory Post-Writing Log Updates):**
   - เมื่อเขียนจบแต่ละบท ต้องอัปเดตไฟล์บันทึกระบบทันทีทุกครั้ง:
     * สรุปเนื้อหาลงใน `chapters_summary.md`
     * ประวัติการแกะกล่องพัสดุและตัดยอดทรัพยากรลงใน `unboxing_log.md` และ `items.md`
     * อัปเดตตารางประวัติการเขียนท้ายไฟล์ `prompt.md`

5. **กฎเหล็กการ Git Commit & Push ทุกครั้ง (Mandatory Git Push Rule):**
   - ทุกครั้งหลังเขียนบทใหม่ แก้ไขเนื้อหา หรืออัปเดตไฟล์ระบบเสร็จสิ้น **ต้องทำ Git Commit และ Git Push ขึ้นสู่ GitHub (`origin/main`) เสมอ 100% ทันที**

## 🚫 หมวดที่ 2: บัญชีข้อห้ามเด็ดขาด (Strict Prohibitions & Ban List)

### 1. ❌ ห้ามบรรยายแก้ตัวหรือโต้เถียงกับผู้อ่านในเนื้อเรื่อง (No Meta-Excuses in Prose)
- ห้ามแทรกเสียงผู้เขียนหรือบทบรรยายแก้ต่างเรื่องฟิสิกส์ วิทยาศาสตร์ หรือความไม่สมเหตุสมผลในเนื้อนิยาย
- **หลัก Action-First Correction:** หากพบจุดขัดแย้ง ให้แก้ที่การกระทำของตัวละครทันที และตัดสิ่งที่ไม่สมจริงทิ้งไปทั้งหมด

### 2. ❌ ห้ามคนยุคหินพูดภาษาไทยสละสลวยหรือพูดคล่องแคล่วเกินยุค (No Fluent Modern Speech by Primal Humans)
- ห้ามให้มนุษย์ยุค 10,000 ปีก่อนพูดประโยคยาว สละสลวย หรือภาษาแบบนิยายกำลังภายใน
- **5 เสาหลักการสื่อสารยุคหิน:**
  1. คำศัพท์รากฐานสั้น ห้วน ดิบ: *"ทอร์"* (ไฟ), *"ซอล"* (เกลือ), *"อาคา"* (น้ำ), *"ซัว"* (เพื่อน), *"โอร็อก"* (ศัตรู)
  2. ภาษามือพรานป่า (แตะหน้าผาก, ปาดคอ, ทุบอกซ้าย)
  3. วาดแผนที่บนดินและหิมะ
  4. แสดงท่าทางกายภาพเลียนแบบ (Physical Pantomime)
  5. ให้เอลยา/ทาร่าเป็นสะพานเชื่อมภาษา

### 3. ❌ ห้ามใส่วงเล็บภาษาอังกฤษในฉบับภาษาไทย ยกเว้นชื่อยาและวัสดุเฉพาะทาง (Ban on English Parentheses)
- ใน `*_th.md` ห้ามใส่ `(English)` กำกับคำศัพท์ทั่วไป (เช่น `(Zone Red)`, `(Flashblind)`)
- **ข้อยกเว้นที่อนุญาตเฉพาะ:**
  * **ชื่อยา/เวชภัณฑ์:** เช่น `(MEBO)`, `(Amoxicillin)`, `(Lidocaine 2%)`, `(Paracetamol)`
  * **ชื่อวัสดุ/เกรดโลหะเฉพาะทาง:** เช่น `(1095 High Carbon Steel)`, `(5160 Spring Steel)`, `(Polypropylene / PP)`, `(Duct Tape)`, `(Paracord 550)`

### 4. ❌ ห้ามใช้คำศัพท์และมโนทัศน์ที่คนยุคหินไม่มีทางรู้จัก (No Anachronistic Concepts)
- ห้ามใช้คำว่า: *"มังกร (Dragon)"*, *"สวรรค์ชั้นเจ็ด"*, *"นรก"*, *"เทคโนโลยี"*, *"วิทยาศาสตร์"*, *"โรงงาน"*, *"หุ่นยนต์"*
- ให้เปรียบเทียบกับสัตว์ดึกดำบรรพ์จริง (แรดยักษ์ขนยาว, แมมมอธ, เสือเขี้ยวดาบ, หมีถ้ำ, กวางไอริช) หรือธรรมชาติรอบตัว (อสูรเหล็ก, ศิลาดำ, ดวงตาสุริยะ)

### 5. ❌ ห้ามยิงกระสุนปืน .38 Special พร่ำเพรื่อ (Preserve .38 Ammo)
- กระสุน .38 Special มี **43 นัด** ต้องรักษาไว้ 100% ครบถ้วนบริสุทธิ์ ห้ามยิงจนกว่าจะถึงไคลแมกซ์ชี้ชะตาชีวิต

### 6. ❌ ห้ามเปิดไฟหน้ารถ 10 ล้อทิ้งไว้เด็ดขาด (Preserve 24V & Diesel)
- น้ำมันดีเซล (198.5L) และไฟ 24V มีจำกัด ส่องได้เฉพาะจังหวะสั้นๆ ในการรบช็อกศัตรู

### 7. ❌ ห้ามบรรยายว่าตู้พัสดุแบ่งโซนสินค้าสำเร็จรูปมาจากโรงงาน (Realistic Cargo Stowage)
- พัสดุ 3,500 กล่องจัดเรียงตามสายส่งและน้ำหนัก ปะปนกันแน่น การค้นหาต้องทำตาม Waybill หรือโซนที่ธามจัดระเบียบเองในภายหลัง

### 8. ❌ ห้ามบอกรายการสิ่งของในคลังพัสดุทั้งหมดแก่คนอ่าน (No Full Inventory Spoiler)
- ให้บอกเฉพาะชื่อหมวดกว้างๆ เพื่อรักษาความลุ้นระทึก (Narrative Suspense) ในการเปิดพัสดุ

### 9. ❌ ห้ามกินเมล็ดพันธุ์พืชโดยตรงเด็ดขาด (Strict No-Consumption of Seeds)
- เมล็ดพันธุ์คือทรัพยากรยุทธศาสตร์ ต้องนำไปเพาะพันธุ์และขยายพันธุ์ (Seed Multiplication) เท่านั้น

### 10. ❌ ห้ามขึ้นต้นตอนด้วยการรายงานสภาพอากาศซ้ำซาก (Anti-Cliché Weather Opening)
- ห้ามรายงานตัวเลขอุณหภูมิทื่อๆ หรือเปิดด้วย "หมอกยามเช้า..." ซ้ำๆ ต้องหมุนเวียน 6 รูปแบบการเปิดบท

### 11. ❌ ห้ามส่งสิ่งของกายภาพข้ามมิติ และธามยังกลับไม่ได้เด็ดขาด
- ผ่านได้เฉพาะคลื่นสัญญาณและข้อมูลดิจิทัล สสารทางกายภาพจะถูกแรงโน้มถ่วงมิติฉีกสลาย

### 12. ❌ ห้ามมีดราม่าอิจฉาริษยาระหว่างนางเอกทั้งสอง (Dual Heroines Harmony)
- เอลยาและหมอณิชาให้เกียรติและกลมเกลียวกัน ไร้ดราม่าน้ำเน่า

## ✍️ หมวดที่ 3: กฎการเล่าเรื่องและตัวละคร (Narrative & Character Rules)

1. **Two-Way Uplift:** ธามถ่ายทอดวิทยาการ ชนเผ่าถ่ายทอดวิชาป่าและสัญชาตญาณเอาชีวิตรอด
2. **Younger Dryas Progression:** เดือนที่ 1–2 (ปลายใบไม้ร่วง 5–18°C), เดือนที่ 3–4 (ต้นหนาว -3 ถึง 7°C), เดือนที่ 5 เป็นต้นไป (หนาวสุดขั้ว -25 ถึง -5°C)
3. **Base Building:** พัฒนา Fortress Alpha ต่อเนื่องทุก 1–2 ตอน (ประปาไผ่, โซลาร์, แปลงผัก, คอกสัตว์, เรือนพัก 10–15 หลังคาเรือน)
4. **6 Episode Archetypes:** สลับหมุนเวียน Type A ถึง Type F ไม่ซ้ำซาก
5. **Forum Dynamic:** สมาชิกหลัก + ผู้เชี่ยวชาญเฉพาะทาง + เกรียนคีย์บอร์ด ไม่ใช้ชื่อ User เดิมซ้ำทุกตอน

## 📦 หมวดที่ 4: สถานะทรัพยากรหลักที่ต้องติดตาม (Core Resource Counters)

- **กระสุนปืนลูกโม่ .38 Special:** **43 นัด** (ครบ 100%)
- **กระสุนปืนยิงพลุ 26.5 มม.:** คงเหลือ **2 นัด**
- **น้ำมันดีเซลคงเหลือ:** **198.5 ลิตร**
- **เกลือสมุทรบริสุทธิ์:** **8,420 กรัม**
- **ซุปก้อนคนอร์:** **10.0 ก้อน**
- **พัสดุในตู้รถ:** แกะแล้ว 31 กล่อง, คงเหลือประมาณ **~3,468 กล่อง**
